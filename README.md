# CONCEPTLAB

**Understand. Experiment. Discover.**

CONCEPTLAB is an interactive concept-learning platform designed to help people understand how the world works through visual explanations, experiments, prediction, and reflection.

## Current milestone
- Flutter app foundation
- Deep Navy + Electric Blue visual system
- Animated Abstract Energy Core homepage hero
- Home, Explore, Lab, Learn, and Profile navigation
- Starter learning categories and progress card

## Run locally
1. Install Flutter (stable) and Android tooling.
2. Clone this repository.
3. Run `flutter pub get`.
4. Run `flutter run`.

## Project status
This is an early MVP foundation. AI tutoring, verified scientific simulations, accounts, persistence, and full learning modules are planned for later milestones. The current interface uses sample content.

## Product principle
**Understand → Experiment → Predict → Explain → Remember**

Scientific content and simulation outcomes should be validated before being presented as facts.
